## CIとOpenEMR

OpenEMRは[run 40213801704](https://github.com/Suisan-neki/mugiurushi/actions/runs/40213801704)のsoapとmanual-trialが成功した。固定したOpenEMR・MariaDB・Playwright Chromium 151を使い、架空の患者データだけで実行した。

| ケース | 確認できた結果 |
| --- | --- |
| normal | 患者と受診の対応、SOAPの4項目のDB行とサーバーからの再表示を照合し、条件を満たした |
| database-stopped | 保存直前にDBを停止し、実際に保存を試みた。保存先の読出しは未観測、HTTPの確認は失敗で、条件を満たさなかった |
| retry | 新しいDBとコンテナで正常条件を再試行し、同じ観測を通過した |
| database-stopped-recovered | 同じDBを起動し直し、両サービスの準備とSELECT 1を確認。故障中は読めなかった患者・受診が各1行、SOAPの各項目と識別用の行は0行と読めた。元の判定はnot_satisfiedのまま |
