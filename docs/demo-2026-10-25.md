## 見せる流れ

技術者／非技術者を選ぶ → 公開GitHubを読む → システム構成図を確認する → 図の一部への疑問をAIと整理する → 人が期待を確認する → 実際に試す → 結果と未確認事項を元の図で確認する → 改修後に再試験し、前後を比べる。

この一往復を実対象1件で通すことを日曜日向けの目標にする。番号表示は「42を保存したのに43が表示される」という問題を説明しやすい候補だが、生成した図から同じ対象の実試験までを通せることは未確認。既存の番号表示用記録を開く操作と、任意のGitHubから始める操作を、接続確認なしに一つの実演として扱わない。
